# Nostra

Nostra is a fashion e-commerce website project built with HTML, CSS, and JavaScript. It gives visitors a simple way to explore a collection, view products, and move between pages.

## About the Project

This project was created to practice building a complete website experience, from page layout and styling to interactive elements. It includes a home page and supporting pages for browsing products and learning more about the store.

## Features

- Home page with promotional content
- Product collection with images and descriptions
- Navigation between website pages
- Search or filtering features, if included in the project
- Responsive layout for different screen sizes
- Interactive elements powered by JavaScript

## Pages

- **Home** — introduces the store and highlights featured content
- **Collections** — displays products or categories
- **About Us** — provides information about the store
- **Contact** — shares contact details or a contact form

## Built With

- HTML
- CSS
- JavaScript
